# 🎬 Aplicación de Registro de Películas con React

Esta aplicación permite registrar películas mediante un formulario, guardarlas en el localStorage del navegador y mostrarlas en tarjetas (cards). Está desarrollada con **React**, **React-Bootstrap** y **SweetAlert2**.


---

## **📌 Tecnologías Usadas**  
| **Tecnología**       | **Uso**                              |  
|----------------------|--------------------------------------|  
| ⚛ React             | Biblioteca principal para la UI.     |  
| 🎨 React-Bootstrap  | Diseño responsive y componentes.     |  
| 📝 SweetAlert2      | Ventana de confirmación de borrado . |  
| 🚀 Vite             | Entorno de desarrollo rápido.        |  

---


## **🛠 Instalación y Ejecución**  

1. **Clona el repositorio**  
   ```bash
   git clone https://github.com/hernanortiz1/ejercicio10React.git
   cd lista-tareas-react
   ```

2. **Instala las dependencias**  
   ```bash
   npm install
   ```

3. **Ejecuta el proyecto**  
   ```bash
   npm run dev
   ```
   Abre tu navegador en: [http://localhost:5173](http://localhost:5173)  

---
## **📋 Funcionalidades Principales** 

- Formulario con los siguientes campos:
  - 📌 Nombre (campo de texto)
  - 📝 Descripción (textarea)
  - 🎞️ Género (select: Comedia, Drama, Infantil)
- Validación de campos usando Bootstrap
- Guardado de películas en `localStorage`
- Visualización de las películas en tarjetas
